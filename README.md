# W Linux

![W Linux — the default wallpaper of theme `w`](banner.webp)

**English** · [Русский](docs/ru/README.md)

**W is Arch Linux, built into one whole system.** A Wayland desktop on Hyprland
with a shell written for it, one theme across every application, and a system you
can always take back to yesterday. Every install brings fresh Arch packages; the
configuration underneath is fixed and tested.

**[Website](https://tarkh.github.io/w-website/) · [Download](https://tarkh.github.io/w-website/en/download.html) · [Documentation](https://tarkh.github.io/w-website/en/docs.html)**

---

## Why W

- **Everything is reversible.** A snapshot comes before every package
  transaction and every W update. Boot any of them from the boot menu, or roll
  back from the Hub.
- **One theme for everything.** One palette paints the desktop, terminals, GTK
  and Qt apps, Firefox, the boot menu and the boot splash. A new theme starts
  from any wallpaper.
- **A desktop that feels finished.** Hyprland with a shell made for it: the bar,
  the launcher, notifications and the Hub with every setting in one place — all
  of it works from the keyboard.
- **Secure from the first boot.** Full-disk encryption by default, Secure Boot
  and TPM2 unlock without changing your firmware keys, a firewall and encrypted
  DNS — set up by the installer, not left as homework.
- **At home next to Windows.** Install into free space: Windows stays untouched
  and one entry away in W's boot menu.
- **Updates that respect your edits.** W updates what it owns and never
  overwrites the configuration you have made your own.
- **Extras when you want them.** W-Packs set up development, containers, audio,
  3D, gaming and more in one click. An AI assistant that knows the system stays
  off until you turn it on.

## Get started

1. **[Download the image](https://github.com/tarkh/w/releases/tag/edge)** — rebuilt
   every night, so it installs today's packages.
2. **Boot it.** Secure Boot can stay on.
3. **Answer the installer and reboot.** The first boot finishes the setup.

Requirements and every step in detail: [INSTALL.md](INSTALL.md).

> **Beta.** W is its author's daily system, but it is young — back up your data
> before you install.
