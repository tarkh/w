Использование: w-record <режим> [действие] | stop | status [--porcelain]
                        | get [KEY] | set KEY VALUE

Info: Запись экрана — область/окно/монитор, одна клавиша на старт и стоп.

Режимы:
  region    Выделить прямоугольную область
  window    Записать окно в фокусе (геометрия Hyprland)
  output    Записать монитор в фокусе

Действия (по умолчанию: toggle):
  --toggle  Начать запись или остановить уже идущую. Именно это делают бинды:
            одно и то же сочетание и начинает дубль, и заканчивает его.
  --start   Только начать; ошибка, если запись уже идёт

Команды:
  stop      Остановить запись и корректно закрыть файл
  status    Показать, идёт ли запись, чего именно и сколько времени
  get       Вывести все настройки как KEY=value (+ BACKENDS) или одно значение
  set       Изменить одну настройку для своей учётной записи

Настройки (действуют со следующей записи):
  RECORDER  wf (wf-recorder; gsr приедет отдельным W-Pack)
  ENCODER   auto | cpu | vaapi — где выполняется кодирование
  AUDIO     system | mic | none — что попадёт на звуковую дорожку
  FORMAT    mp4 | mkv | webm; webm всегда кодируется на процессоре
  FRAMERATE постоянная частота кадров, 1-240; по умолчанию 30
  WINDOW_MASK yes | no — закрасить скруглённые углы записи `window` чёрным вместо
            обоев за ними; yes всегда кодирует на CPU

Коды выхода:
  0  Успех или пользователь отменил выделение
  1  Ошибка выполнения
  2  Ошибка вызова

Примеры:
  w-record output                    # монитор в фокусе; нажать снова — стоп
  w-record region --start            # выделить область; занято — ошибка
  w-record stop                      # закрыть файл и уведомить
  w-record status --porcelain        # состояние для машинного чтения
  w-record set AUDIO mic             # озвучка вместо звука рабочего стола
