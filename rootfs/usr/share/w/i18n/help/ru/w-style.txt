Использование: w-style <команда> [параметры]

Info: Отрисовка активной темы во всех оформляемых подсистемах.

Команды:
  apply [<подсистема>|user|all]  Перерисовать активную тему (по умолчанию: all)
  set <ТОКЕН> <#hex>             Поправить один токен системной темы и применить
  status                         Ключевые вычисленные цвета (системная тема)

Подсистемы (в порядке применения — [область] user | system | dual):
$SUBSYSTEMS

  user   = все оси области user в \$HOME (или /etc/skel от root); отрисовка входа, без системы
  all    = область user (skel) + системные оси; требует root (время установки)

Область: оси user → действующая тема вызвавшего; системные оси → системный фолбэк
         (/etc/w/active-theme); оси dual → каналы пользователя + системные, если root.

Коды выхода:
  0  Успех
  1  Ошибка выполнения
  2  Ошибка вызова

Примеры:
  w-style apply hyprland
  w-style apply all
  w-style set W_PALETTE_ACCENT "#9d6fa8"
  w-style status
