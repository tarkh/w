Использование: w-logs <команда>

Info: Срок хранения логов W (журнал + /var/log + собственные логи W), одна политика.

Команды:
  status               Занятое место + текущее хранение по всем узлам (по умолчанию)
  keep <дней>          Хранить <дней> истории везде, затем применить
  limit <размер>|off   Ограничить размер (журнал целиком / logrotate на файл); off с
  vacuum time <срок>   Подрезать журнал СЕЙЧАС до срока (напр. 2w, 30d, 6month)
  vacuum size <размер> Подрезать журнал СЕЙЧАС до общего размера (напр. 500M, 2G)
  apply                Перегенерировать все узлы из $CONF (после ручной правки)
  show [юнит] [-p P] [-n N]   Читать свежий журнал (проброс в journalctl)
  help                 Показать эту справку

Источник политики: $CONF   (в генерируемых файлах есть баннер «не править»)

Коды выхода:
  0  Успех   1  Ошибка выполнения   2  Ошибка вызова

Примеры:
  w-logs status
  sudo w-logs keep 14
  sudo w-logs limit 1G
  sudo w-logs vacuum time 7d
