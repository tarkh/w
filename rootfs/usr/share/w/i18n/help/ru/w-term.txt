Использование: w-term [команда]

Info: Запуск и опрос настроенного терминала (единая точка входа).

Команды:
  (нет)           Открыть новое окно терминала
  -e КОМ [АРГ…]   Выполнить КОМ в новом окне терминала
  get             Напечатать имя активного терминала
  list            Список известных терминалов (* = активный)
  set <имя>       Задать активный терминал (пишет переопределение юзера)
  help            Показать эту справку

Опции:
  --hold          С \`-e\`: когда КОМ завершится, спросить перед закрытием окна,
                  чтобы вывод остался читаемым. Любой ответ кроме «да» отдаёт
                  окно интерактивной оболочке вместо закрытия

Конфиг: $SYS_CONF (дефолт вендора) + $USER_CONF (переопределение пользователя)

Коды выхода:
  0  Успех   1  Ошибка выполнения   2  Ошибка вызова

Примеры:
  w-term
  w-term -e btop
  w-term --hold -e sudo w-pack remove containers
  w-term set ghostty
