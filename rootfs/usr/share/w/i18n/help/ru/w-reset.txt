Использование: w-reset <модуль|бандл|--all> [файл] [--user <имя>]

Info: Принудительный возврат конфига любого модуля или бандла W к дефолту.

Принудительно вернуть конфиг модуля к дефолту W (текущая копия сначала
сохраняется). Спасение для сломанного руками конфига, без ожидания обновления.
С установленными бандлами W-Pack работает так же — по имени бандла.

Команды:
  <модуль>          Сбросить все пути модуля (см. 'w-reset list')
  <модуль> <файл>   Сбросить один путь относительно домашнего каталога
  <бандл>           Так же сбросить конфиг установленного бандла W-Pack
  --all             Сбросить все модули и все установленные бандлы
  list              Список модулей и бандлов, у которых есть манифест сброса
  check             Показать, какие управляемые файлы отошли от дефолта W
                    (только чтение; ничего не восстанавливается)
  status            Показать, какие эталонные источники доступны

Параметры:
  --user <имя>      Работать с домашним каталогом другого юзера (только root;
                    по умолчанию вызвавший, либо SUDO_USER / основной uid-1000)

Область и права:
  Сброс домашнего конфига в СВОЁМ каталоге root не требует. Чужой дом или
  любой системный путь / переопределение (/etc, /usr, /etc/w) требует sudo.

Коды выхода:
  0  Успех
  1  Ошибка выполнения (нет источника, нет прав, неизвестный модуль)
  2  Ошибка вызова

Примеры:
  w-reset check                       # что отошло от дефолта W
  w-reset shell                       # вернуть конфиг шелла к дефолту
  w-reset quickshell config/bar.json  # один файл
  w-reset dev                         # конфиг бандла W-Pack в вашем доме
  sudo w-reset dns                    # система + /etc/w, нужен root
  sudo w-reset --all --user alice
