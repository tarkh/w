Использование: w-ssh <команда>

Info: Выбор SSH-агента сессии и генерация из него пер-хостовых селекторов ключей.

Команды:
  status            Активный агент, состояние сокета, сгенерированные селекторы
  list              Список известных бэкендов агента (* = активный)
  use <имя>         Сменить SSH-агент (см. list; 'none' = без агента)
  link              Перенаправить постоянный сокет на активный бэкенд (хук входа)
  sync              Пересоздать пер-хостовые селекторы из ключей агента
  include           Добавить строку Include для config.d в $USER_CONFIG
  help              Показать эту справку

Каталог и выбор: слоёный ssh.conf (источник: w-conf cat ssh)
Генерируется (НЕ править): $GEN + $KEYS_DIR/

Коды выхода:
  0  Успех   1  Ошибка выполнения   2  Ошибка вызова

Примеры:
  w-ssh use bitwarden
  w-ssh sync
  w-ssh status
