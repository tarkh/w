`w-info` — List all W tools with a one-line description of each..

## Usage

```
Usage: w-info [help]

Info: List all W tools with a one-line description of each.

W Linux — tool catalog and system overview.

Calling without arguments lists all user-facing w-* utilities with a
short description extracted from each tool's help output.

Commands:
  help    Show this help

Exit codes:
  0  Success
  2  Usage error
```
