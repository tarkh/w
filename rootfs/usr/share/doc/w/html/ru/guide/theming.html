    Темы и обои

    Тема в W — это одна палитра, которую система накладывает на каждую поверхность: интерфейс Hyprland, шелл Quickshell, приложения GTK и Qt, терминал, GRUB, Plymouth, экран входа. Переключение темы полностью меняет оформление везде и сразу — вплоть до цвета логотипа на загрузке — с живым перекрёстным затуханием.

    Переключение тем #

    Хаб → Оформление показывает список установленных тем с превью обоев. Клик по теме переключает её для вашего пользователя; общесистемная смена делается из терминала администратором (w-theme set <name> с правами). Список разбит на два раздела: Системные темы и Мои темы (личные, созданные вами).

    Из терминала: w-theme list и w-theme set <name>.

    Создание темы из обоев #

    Хаб → Оформление → Добавить тему (или w-theme new в терминале) строит тему из изображения:

    1. Выберите картинку для обоев и имя, укажите Тёмная или Светлая.
    2. W извлекает из изображения доминирующие цвета и строит доступную палитру вокруг выбранного базового цвета — контраст проверяется автоматически, чтобы текст оставался читаемым в обоих режимах.
    3. Выберите интенсивность (низкая/средняя/высокая) для рампы палитры и подтвердите.

    Светлым темам уделено особое внимание: цвета текста пересчитываются под светлые поверхности, чтобы кнопки и иконки не теряли контраст.

    Тот же экран, открытый значком карандаша у одной из ваших сгенерированных тем, пересобирает эту тему из её собственных обоев (новый базовый цвет, новый контраст) — сами обои не меняются.

    Обои — это изображения под конкретные разрешения в небольшом наборе размерных тиров; тема отдаёт то, что у неё есть, а система подставляет ближайший размер. Смотрите w-wallpaper, если вы сопровождаете набор ассетов темы.

    Панель Оформление #

    • Вкладка Темы — сетки тем выше, плюс создание и удаление тем.
    • Вкладка Бар — какие блоки бара показаны, по монитору (см. w-bar).
    • Вкладка Настройки — блюр подложки, переключатели анимации и расположение бара.

    Управление темами из терминала #

    w-style отрисовывает тему на каждой подсистеме, w-theme управляет тем, какая тема активна и что существует, w-wallpaper управляет файлами обоев. Для ручного сопровождения (например, после правки системной темы руками): w-style apply перерисовывает, w-reset all возвращает настройки W.
