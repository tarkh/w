    w-bar

    w-bar — Выбор блоков статус-панели для каждого монитора (Хаб W -> Оформление -> Панель).

    Использование #

    Использование: w-bar <команда> [аргументы]

Info: Выбор блоков статус-панели для каждого монитора (Хаб W -> Оформление -> Панель).

Команды:
  status [--porcelain]                  Панель вкл/выкл по мониторам + состояние блоков
  list [<монитор>] [--porcelain]        Каталог блоков (id, тип, зона, родитель); с
                                        монитором — их вкл/выкл для него
  monitor <монитор> <on|off>            Включить/выключить всю панель на мониторе
  block <монитор> <id> <on|off|default> Показать/скрыть один блок; "default" снимает
                                        переопределение и снова следует bar.json
  reset [<монитор>]                     Снять переопределения (для монитора или все)
  help                                  Показать эту справку

Блоки адресуются по "id" из bar.json (уникален в пределах файла, включая вложенные
элементы зон). Блок без id рисуется как обычно, но адресовать его отсюда нельзя.

Конфиг: $BAR_JSON
GUI: Хаб W -> Оформление -> Панель

Коды выхода:
  0  Успех   1  Ошибка выполнения   2  Ошибка вызова

Примеры:
  w-bar status
  w-bar block eDP-1 tray off
  w-bar monitor HDMI-A-1 on
  w-bar block HDMI-A-1 systemMonitors default

    Эта страница генерируется из собственной справки команды (w-docs-refgen). Живая версия того же текста на машине с W: w-bar help.
