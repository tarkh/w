    w-ai

    w-ai — Запуск и настройка AI-ассистента W — хосты, ключи, память, вопросы.

    Использование #

    Использование: w-ai [--host <имя>] [команда]

Info: Запуск и настройка AI-ассистента W — хосты, ключи, память, вопросы.

Запуск (по умолчанию, если команды нет):
  w-ai                  Запустить ассистента с настроенным хостом
  w-ai --host <имя>     Заменить хост на запуск (goose|local|claude|codex|opencode)

Команды:
  ask <текст…>          Начать сессию с заданным вопросом и остаться в
                        интерактивном режиме (это вызывает палитра «Спросить W»
                        в Quickshell; пустой текст = обычный запуск)
  ready                 Код 0, если текущая конфигурация готова к запуску (бинарь
                        хоста на месте, вход в него активен или API-ключ в
                        связке, модель задана там, где хосту она нужна); иначе
                        код 1 + слово-причина. Используется точкой входа
                        «Спросить W» в Quickshell перед открытием.
  status                Хост/провайдер/модель, наличие ключа, самопроверка w-mcp
  config                Править персональное переопределение (~/.config/w/ai.conf)
  host list [--porcelain]   Хосты (goose|local|claude|codex|opencode) и их состояние
  host status [<н>]     Показать контракт одного хоста (hosts/<н>/host.conf)
  host install <н>      Установить CLI хоста родным установщиком вендора
  host login [<н>]      Войти в хост со своей авторизацией (Claude Code, Codex)
  features [--porcelain]           Состояние продвинутых функций (пак ai-extra):
                        ddgs/trafilatura/ollama/модель эмбеддингов/numpy,
                        конфиг семантической памяти, размер векторного корпуса
  features set <КЛЮЧ> <значение>   Задать один ключ продвинутых функций (W_AI_EMBED|
                        W_AI_EMBED_MODEL|W_AI_EMBED_URL|W_AI_EMBED_KEEPALIVE|
                        W_AI_SEARCH_PROVIDER) в ~/.config/w/ai-features.conf
  profile list          Список профилей провайдеров, активный помечен
  profile new <н> [--from <база>]   Создать профиль (пустой или копией из <базы>)
  profile edit <н>      Править профиль в \$EDITOR
  profile show <н>      Напечатать содержимое профиля
  profile use <н>       Сделать <н> активным профилем (копирует его в ai.conf)
  profile rm <н>        Удалить профиль
  profile field <н> <КЛЮЧ> <значение>   Задать одну строку KEY=VALUE в профиле
                        (раскомментирует закомментированный дефолт, если он есть;
                        редактор полей в Хабе использует это вместо \$EDITOR)
  key set <провайдер>   Сохранить API-ключ провайдера в связке ключей (спросит)
  key rm  <провайдер>   Удалить API-ключ провайдера из связки ключей
  key list              Показать, у каких провайдеров есть ключ
  memory list           Список сохранённых воспоминаний ассистента (общие для хостов)
  memory search <з>     Найти воспоминания по запросу
  memory add            Записать новое воспоминание в \$EDITOR (шаблон frontmatter)
  memory rm <slug>      Удалить воспоминание по slug
  memory context        Напечатать блок контекста памяти для начала сессии
  memory review         Гигиена: возраст, что в контексте, подсказки о протухшем
  task list [статус]    Список задач (по умолчанию открытые; ещё done|all)
  task add <текст…>     Добавить открытую задачу (можно дописать --due ГГГГ-ММ-ДД)
  task done <slug>      Отметить задачу выполненной
  skills list           Системные и пользовательские скилы (надстройка агента)
  skills show <имя>     Напечатать SKILL.md одного скила
  skills rm <имя>       Удалить пользовательский скил (системные защищены)
  recipe list           Доступные рецепты автоматизации (система + надстройка)
  run-recipe <имя>      Выполнить один рецепт headless через goose, однократно
                        (внутренняя точка входа таймера; руками запускать безопасно)
  schedule add <рецепт> <OnCalendar>   Запускать рецепт по таймеру systemd юзера
  schedule list          Список активных расписаний рецептов
  schedule rm <рецепт>   Убрать расписание рецепта
  help                  Показать эту справку

Конфиг: $SYS_CONF (системный) поверх него $USER_CONF (пользовательский).
Секреты: gnome-keyring (атрибут $KEY_ATTR=<провайдер>); ничего в открытом виде.

Коды выхода:
  0  Успех   1  Ошибка выполнения   2  Ошибка вызова

Примеры:
  w-ai key set openrouter
  w-ai --host local
  w-ai host install claude
  w-ai status
