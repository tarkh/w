    w-monitor

    w-monitor — Настройка мониторов (разрешение, масштаб, поворот, расположение).

    Использование #

    Использование: w-monitor <команда> [аргументы]

Info: Настройка мониторов (разрешение, масштаб, поворот, расположение).

Команды:
  list [--porcelain]              Активные выходы (имя, режим, масштаб, раскладка...)
  modes <монитор> [--porcelain]   Список режимов активного выхода
  scales <монитор> [ШxВ] [--porcelain]  Масштабы, которые Hyprland принимает для активного
                                   выхода (или для заданного режима) — см. "scale"
  status [--porcelain]            Сохранённые правила из фрагмента + основной монитор
  mode <монитор> <ШxВ@Гц|preferred>   Задать разрешение / частоту обновления
  scale <монитор> <дробное|auto>      Задать масштаб (только из принимаемых Hyprland для
                                       режима выхода — их перечисляет "scales"; иначе
                                       композитор отвергнет его и подставит свой)
  transform <монитор> <0|90|180|270>  Задать поворот
  place <монитор> <right|left|above|below|auto>   Задать положение в раскладке
  enable <монитор>                Снова включить отключённый выход
  disable <монитор>               Отключить выход (нельзя основной или последний включённый)
  primary <монитор>               Назначить основной монитор (включит его; там живёт главная панель)
  sanity                          Включить один выход, если отключены ВСЕ подключённые
                                   (запускать до старта композитора; иначе ничего не делает)
  reset <монитор>|--all           Сбросить правило(а), вернуться к авто
  greeter status [--porcelain]        Действующий конфиг экрана входа (root не нужен)
  greeter sync                        Скопировать раскладку сессии в экран входа (root)
  greeter primary <монитор>           Основной монитор экрана входа (root, включит его)
  greeter apply <спека>...            Задать всю раскладку экрана входа разом (root); спека =
                                       <выход>:<режим>:<масштаб>:<поворот>:<позиция>:<on|off|primary>
                                       (не более одной спеки может сказать "primary" — это
                                       подразумевает on и пишется как основной монитор)
  greeter reset                       Снять переопределение экрана входа, вернуть авто (root)
  greeter sanity                      То же спасение, что "sanity", для экрана входа (root)
  help                            Показать эту справку

Правила хранятся в: $FRAG   Зеркало состояния: $STATE
Правила экрана входа: $GREETER_FRAG   Его состояние: $GREETER_STATE

Коды выхода: 0 успех · 1 ошибка выполнения/проверки · 2 ошибка вызова

Примеры:
  w-monitor mode eDP-1 1920x1080@60
  w-monitor scales eDP-1
  w-monitor scale eDP-1 1.5
  w-monitor place HDMI-A-1 right
  w-monitor primary eDP-1
  w-monitor reset HDMI-A-1

    Эта страница генерируется из собственной справки команды (w-docs-refgen). Живая версия того же текста на машине с W: w-monitor help.
