    w-session

    w-session — Запоминание и восстановление сессии (окна, рабочие столы, раскладка).

    Использование #

    Использование: w-session <команда> [аргументы]

Info: Запоминание и восстановление сессии (окна, рабочие столы, раскладка).

Команды:
  status [--porcelain]        Режим и что сейчас сохранено
  save                        Снять снимок сессии сейчас
  restore [--dry-run]         Открыть сохранённую сессию (--dry-run перечислит)
  close [--workspace <имя>] [--timeout <сек>] [--keep-snapshot]
        [--until-cancelled] [--dry-run]
                              Попросить все окна закрыться и дождаться их,
                              оставив диалог «Сохранить изменения?» доступным.
                              Код 1, если окно осталось открыто — юзер отменил
                              диалог. --keep-snapshot: тогда сохранённая сессия
                              держится, пока не откроется новое окно (отменённый
                              выход). --until-cancelled: без лимита времени;
                              уведомление ждёт окна, нажатие на него отменяет.
                              --dry-run печатает, скольких попросили бы.
  forget                      Удалить сохранённую сессию
  layout list [--porcelain]   Показать сохранённые именованные раскладки
  layout save <имя> [--workspace]
                              Сохранить все рабочие столы под именем <имя> или
                              только текущий (--workspace) — тогда он применится
                              на тот стол, который будет в фокусе потом
  layout apply <slug> [--dry-run] [--foreground]
                              Закрыть открытое (диалоги сохранения остаются
                              доступными, отмена одного прерывает всё) и открыть
                              раскладку. Работает отдельно от терминала, ведь
                              закрывает и тот, в котором набрана; --foreground
                              оставляет привязку, чтобы наблюдать по ssh.
                              --dry-run только печатает, сколько окон закрылось
  layout delete <slug>        Удалить сохранённую раскладку
  mode <off|save|restore>     off: ничего не писать · save: только писать ·
                              restore: писать и открывать при входе
  autosave <секунды>          Порог фонового снимка (0 = только штатный выход)
  terminal <off|allowlist|all>
                              Открывать заново программу, запущенную в терминале
  exclude list                Показать шаблоны классов, которые не записываются
  exclude add <regex>         Никогда не записывать окна этого класса
  exclude remove <regex>      Убрать шаблон обратно
  daemon                      Запустить демон снимков (w-session-save.service)
  help                        Показать эту справку

Снимок: ~/.local/state/w/session.json   Настройки: w-conf cat session
Именованные раскладки: ~/.local/share/w/layouts/
Переопределения перезапуска: ~/.config/w/session-apps.tsv
Белый список терминалов: ~/.config/w/session-terminal.list

Коды выхода: 0 успех · 1 ошибка выполнения/проверки · 2 ошибка вызова

Примеры:
  w-session mode restore
  w-session exclude add 'steam_app_.*'
  w-session restore --dry-run
  w-session layout save 'Работа'
  w-session layout save 'Чтение' --workspace
