    w-update

    w-update — Обновление всех системных и AUR-пакетов (репозитории + AUR за один проход).

    Использование #

    Использование: w-update [команда]

Info: Обновление всех системных и AUR-пакетов (репозитории + AUR за один проход).

Команды:
  (нет) | upgrade    Интерактивное полное обновление: репозитории + AUR (yay -Syu
                     --sudoloop), затем обновление статуса и предложение
                     перезагрузиться, если сменилось ядро.
  plan [--porcelain] Предпроверка (только чтение): что затронет обновление из
                     репозиториев, что ждёт в AUR, ядро/перезагрузка, место на
                     диске. Основа обновления через AI.
  check [--packs]    Обновить счётчик обновлений + флаг перезагрузки (без root,
                     тихо). Пишет $STATE_FILE для блока панели. Обновления
                     движков паков (w-pack outdated) проверяются не чаще раза
                     в 6 ч; --packs проверяет их сейчас.
  status             Напечатать последний известный статус обновлений + состояние
                     проверяльщика.
  news               Показать свежие новости Arch Linux (читать перед обновлением).
  enable             Включить периодическую проверку обновлений для этого юзера.
  disable            Выключить периодическую проверку обновлений для этого юзера.
  interval [мин]     Показать или задать интервал проверки (таймер systemd юзера).
  help               Показать эту справку.

Файл статуса: $STATE_FILE   Таймер: $TIMER_UNIT (по умолчанию $DEFAULT_INTERVAL)

Коды выхода:
  0  Успех   1  Ошибка выполнения   2  Ошибка вызова

    Эта страница генерируется из собственной справки команды (w-docs-refgen). Живая версия того же текста на машине с W: w-update help.
