    w-theme

    w-theme — Переключение, создание и управление темами W с плавным переходом.

    Использование #

    Использование: w-theme <команда> [параметры]

Info: Переключение, создание и управление темами W с плавным переходом.

Команды:
  set <имя> [--no-fade]   Переключить тему.
                            без root → для этого юзера, мгновенно, с переходом
                            sudo     → системный фолбэк + skel + загрузка/вход
                            --no-fade  без плавного перехода
  reset                   Снять личную тему, следовать системному фолбэку
  new <имя> --wallpaper <изображение> [параметры]
                          Собрать тему из изображения: обои обрезаются по cover
                          под каждую ступень разрешения, палитра извлекается из
                          них же (matugen + отображение OKLCH).
                            без root → ~/.config/w/themes/, sudo → /etc/w/themes/
                            --appearance dark|light   по умолчанию dark
                            --contrast low|medium|high
                                                      насколько подкрашены
                                                      поверхности и как далеко
                                                      разведены тона; low —
                                                      пастельный край, по
                                                      умолчанию medium
                            --seed-index <n>          какой базовый цвет
                                                      изображения брать за основу
                                                      (0 = самый доминирующий)
                            --scheme <тип matugen>    по умолчанию: adaptive
                            --activate                переключиться на неё сразу
                            --json                    напечатать только матрицу
                                                      палитр, ничего не создавая:
                                                      каждый базовый цвет
                                                      изображения × dark/light ×
                                                      каждый уровень контраста
                                                      (превью для GUI; остальные
                                                      параметры тогда не важны,
                                                      возвращается всё)
  edit <имя> [параметры]  Пересобрать палитру сгенерированной темы на месте,
                          сохранив её обои. Те же параметры, что у `new`, минус
                          изображение (другие обои — это другая тема, для неё
                          `new`), плюс --rename <новоеимя>; что не указано,
                          остаётся как было. Если тема активна, сессия (или
                          система) перекрашивается. Темы, написанные руками,
                          редактировать нельзя.
  rm <имя>                Удалить тему (для системной нужен sudo). Если это ваша
                          активная тема, привязка сначала сбрасывается.
  list [--porcelain]      Список системных и локальных тем (* = активная здесь)
                            --porcelain  TSV: имя, область, каталог, активна, ген.
  current                 Показать действующие темы пользователя и системы

Каталоги тем:
  системные  /etc/w/themes/<имя>/
  локальные  ~/.config/w/themes/<имя>/    (в каждом: theme.conf + wallpaper/)

Сгенерированная тема несёт только theme.conf, wallpaper/ и preview.webp — анимации
геометрия, эффекты, шрифты и база Kvantum наследуются от базовой темы 'w', поэтому
она идёт в ногу с W, а не замораживает копию.

Коды выхода:
  0  Успех
  1  Ошибка выполнения
  2  Ошибка вызова

Примеры:
  w-theme list
  w-theme set midnight
  sudo w-theme set midnight
  w-theme reset
  w-theme new sunset --wallpaper ~/Pictures/sunset.jpg --activate
  w-theme new garden --wallpaper ~/Pictures/park.jpg --seed-index 1 --contrast low
  sudo w-theme new corporate --wallpaper /srv/brand.png
  w-theme edit sunset --contrast low
  w-theme rm sunset
