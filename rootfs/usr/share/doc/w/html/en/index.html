    W Linux documentation

    W Linux is an Arch Linux–based distribution: a Hyprland/Quickshell desktop, a first set of w-* tools that drive the system, and automatic snapshots that make everyday operations reversible. This documentation is viewed in the desktop itself (the ? button in Hub panels, or Super+F1) and published with the repository.

    Getting around #

    • The Hub (Super+Space) is the graphical control center: it is where settings live and where the Hotkeys panel lists every key binding.
    • Super+F1 opens this documentation at any time.
    • w-info lists every w-* command with a one-line description in a terminal.
    • Recovery is the page for "the system does not boot" — it ships as a separate, standalone copy at the same location on every W machine.

    Command reference #

    Every user-facing w-* command has a page under reference/, generated from the command's own help text. The same list is available on any W machine with w-info.

    • w-ai — Launch and manage the W AI assistant — hosts, keys, memory, ask.
    • w-appearance — Per-user overrides that beat the active theme (W Hub -> Appearance -> Settings).
    • w-bar — Choose which status-bar blocks show on which monitor (W Hub -> Appearance -> Bar).
    • w-conf — Read and write W's layered configuration (vendor → admin → user).
    • w-crypt — Manage disk-encryption factors — TPM2 auto-unlock and recovery keys.
    • w-dns — Switch DNS provider and DNS-over-TLS mode (systemd-resolved).
    • w-fingerprint — Enrol, list and delete the fingerprints of the current user.
    • w-firewall — Toggle the firewall zone between home and public (firewalld).
    • w-help — Open the W documentation in the Help window.
    • w-hotkeys — Manage Hyprland keybindings — profiles, catalog, custom binds.
    • w-info — List all W tools with a one-line description of each.
    • w-kbdlight — Keyboard backlight — level, media keys, and light at the LUKS prompt.
    • w-kernel — Select the active kernel and toggle the hardening profile.
    • w-keyboard — Manage the keyboard-layout ring of the Wayland session (XKB).
    • w-langpack — Show and deliver what a locale needs beyond LANG (translations, dictionary, font).
    • w-locale — Show and switch the system UI language (LANG).
    • w-logs — Set how long W keeps logs (journal + /var/log + W's own logs), one policy.
    • w-mirrors — Keep the pacman mirrorlist fresh — rank mirrors on a schedule or on demand.
    • w-monitor — Configure monitors (resolution, scale, rotation, layout).
    • w-nightlight — Night light — warm the screen on a schedule to cut blue light in the evening.
    • w-notify — Control desktop notifications — Do Not Disturb, history, per-app mute.
    • w-pack — Install and inspect optional W software bundles (packs).
    • w-pointer — Manage mouse, touchpad and swipe-gesture settings of the Wayland session.
    • w-power — Power profiles, idle policy (lock/display/suspend), lid/power key, charge limit.
    • w-record — Record the screen — region/window/monitor, one key to start and stop.
    • w-reset — Force-restore any W module's or bundle's config to its default.
    • w-rollback — Roll the system back to a btrfs snapshot, on either boot path.
    • w-screenshot — Capture the screen — region/window/output, annotate/copy/save.
    • w-secureboot — Set up and manage Secure Boot (sbctl keys + Limine hash).
    • w-session — Remember and restore the graphical session (windows, workspaces, split layout).
    • w-ssh — Choose the session's SSH agent and generate per-host key selectors from it.
    • w-style — Render the active theme across all themed subsystems.
    • w-sync — Track the W dev repo (edge channel) and apply updates, keeping user config intact.
    • w-term — Launch or query the configured terminal (single entry point).
    • w-theme — Switch, add and manage W themes with seamless crossfade.
    • w-time — Set the timezone, the system clock and NTP (systemd-timesyncd).
    • w-update — Update all system and AUR packages (repo + AUR in one pass).
    • w-userdirs — Standard home folders (Documents, Pictures, ...) that follow the language.
    • w-wallpaper — Select the wallpaper for the current resolution tier.
