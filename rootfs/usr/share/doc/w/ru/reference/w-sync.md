`w-sync` — Отслеживание dev-репозитория W (канал edge) и обновление без потери настроек.

## Использование

```
Использование: w-sync [команда]

Info: Отслеживание dev-репозитория W (канал edge) и обновление без потери настроек.

Команды:
  (нет) | update    Забрать, показать входящие коммиты, затем предснапшот дома →
                    git pull --ff-only → выборочный apply.sh. Для apply нужен sudo.
  check             Обновить общемашинный счётчик отставания (тихо). Ведут владелец
                    рабочей копии и root; для остальных ничего не делает. Пишет
                    $STATE_FILE; при любом отказе записывает behind:-1 + err,
                    а не ложный 0.
  log               Показать коммиты, которые притянет обновление — для владельца
                    и root берётся живьём, для остальных читается из последней
                    записанной проверки.
  status            Напечатать последний известный статус синхронизации + канал.
  help              Показать эту справку.

Параметры:
  --yes             С 'update': пропустить подтверждение pull/apply и никогда не
                    перезагружаться самому (только сообщить, если нужно). Для
                    неинтерактивных вызовов (путь AI-действий); человеку,
                    запускающему w-sync в терминале, это не нужно.

Канал  : $CHANNEL   Ссылка: $REF   Рабочая копия: $REPO
Статус : $STATE_FILE

Коды выхода:
  0  Успех   1  Ошибка выполнения   2  Ошибка вызова
```

Эта страница генерируется из собственной справки команды (w-docs-refgen). Живая
версия того же текста на машине с W: `w-sync help`.
