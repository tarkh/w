`w-locale` — Показать и переключить язык интерфейса системы (LANG).

## Использование

```
Использование: w-locale <команда> [аргументы]

Info: Показать и переключить язык интерфейса системы (LANG).

Команды:
  status [--porcelain]   Показать текущий LANG
  list [--porcelain] [--names]
                         Список доступных UTF-8 локалей (--names добавляет
                         самоназвание языка и страны через табуляцию)
  set <локаль>           Переключить LANG (root; генерирует локаль,
                         нужен перезаход в сессию)
  help                   Показать эту справку

Конфиг: $CONF   Каталог: $SUPPORTED

Коды выхода: 0 успех · 1 ошибка выполнения/проверки · 2 ошибка вызова

Примеры:
  w-locale status
  sudo w-locale set ru_RU.UTF-8
```

Эта страница генерируется из собственной справки команды (w-docs-refgen). Живая
версия того же текста на машине с W: `w-locale help`.
