`w-kbdlight` — Подсветка клавиатуры — уровень, медиаклавиши и свет на запросе пароля LUKS.

## Использование

```
Использование: w-kbdlight <команда> [значение]

Info: Подсветка клавиатуры — уровень, медиаклавиши и свет на запросе пароля LUKS.

Команды:
  status              Устройство, уровень и политика загрузки (по умолчанию)
  get [--raw]         Напечатать уровень в процентах (--raw: единицы устройства)
  set <N>[%]          Задать уровень (проценты или единицы устройства без '%')
  up [N] / down [N]   Шаг уровня на N процентов (по умолчанию STEP из конфига)
  toggle              Выкл <-> последний ненулевой уровень
  off / restore       Запомнить-и-погасить / вернуть — для слушателя простоя
  device              Напечатать имя найденного устройства подсветки
  boot <N|off>        Уровень для запроса LUKS/загрузки, затем пересборка initramfs
  help                Показать эту справку

Конфиг: /etc/w/kbdlight.conf   (дефолты вендора: /usr/share/w/defaults/kbdlight.conf)
Гашение по простою — часть политики простоя: sudo w-power idle <ac|bat> kbdlight <с>

Коды выхода:
  0  Успех   1  Ошибка выполнения (на этой машине нет подсветки)   2  Ошибка вызова

Примеры:
  w-kbdlight status
  w-kbdlight up
  w-kbdlight set 40%
  sudo w-kbdlight boot 50
```

версия того же текста на машине с W: `w-kbdlight help`.
