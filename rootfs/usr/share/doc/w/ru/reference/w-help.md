`w-help` — Открыть документацию W в окне «Справка W».

## Использование

```
Использование: w-help [страница[#якорь]] [--search запрос]

Info: Открыть документацию W в окне «Справка W».

Аргументы:
  страница        Страница документации — путь Markdown-файла или без
                  расширения: guide/updates, guide/updates.md, faq, recovery.
                  По умолчанию — оглавление. Уже открытое окно без указания
                  страницы только получает фокус
  #якорь          Заголовок на странице (его слаг, как в ссылках «?» Хаба)

Опции:
  --search ЗАПРОС Открыть страницу с уже выполненным поиском ЗАПРОСА
  -h, --help      Показать эту справку

Коды выхода:
  0  Успех   1  Ошибка выполнения (нет такой страницы)   2  Ошибка вызова

Примеры:
  w-help
  w-help guide/updates#where-you-see-updates
  w-help --search snapshot
```

Эта страница генерируется из собственной справки команды (w-docs-refgen). Живая
версия того же текста на машине с W: `w-help help`.
