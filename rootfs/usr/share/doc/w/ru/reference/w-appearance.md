`w-appearance` — Персональные переопределения сильнее активной темы (Хаб W -> Оформление -> Настройки).

## Использование

```
Использование: w-appearance <команда> [значение]

Info: Персональные переопределения сильнее активной темы (Хаб W -> Оформление -> Настройки).

Команды:
  status [--porcelain]              Показать три переопределения и их действующие значения
  bar-position <theme|top|bottom>   Закрепить край панели или вернуть его теме
                                    (GUI: Оформление -> Панель, вместе с остальной панелью)
  blur <theme|off>                  Принудительно выключить размытие Hyprland или вернуть теме
  motion <theme|off>                Принудительно выключить анимации Hyprland или вернуть теме
  help                              Показать эту справку

Конфиг: ~/.config/w/appearance.conf (BLUR/MOTION) + config/bar.json (положение)
GUI: Хаб W -> Оформление -> Настройки (размытие, анимации)
     Хаб W -> Оформление -> Панель    (положение панели; состав панели — `w-bar`)

Коды выхода:
  0  Успех   1  Ошибка выполнения   2  Ошибка вызова
```

Эта страница генерируется из собственной справки команды (w-docs-refgen). Живая
версия того же текста на машине с W: `w-appearance help`.
