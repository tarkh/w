# Fonts

# Universal script coverage — the "no tofu, ever" safety net, the same bet macOS
# makes. Inter and JetBrains cover Latin/Cyrillic/Greek and nothing else, so a
# Japanese web page, a Telegram emoji or a filename in Hindi renders as empty
# boxes without these. Fontconfig needs no change to pick them up: the W
# fonts.conf uses <prefer>, which PREPENDS Inter/JetBrains to the family list and
# leaves the default fallback chain (these) intact — Noto only fills the gaps.
#   noto-fonts       ~107 MiB  all of Unicode except CJK
#   noto-fonts-cjk   ~299 MiB  日本語 / 中文 / 한국어 in one package
#   noto-fonts-emoji  ~10 MiB  colour emoji
# noto-fonts-extra (~331 MiB) is deliberately NOT here: it adds weights and
# widths, not coverage. The ISO does not grow — these ride pacman at install
# time, not the image (see config-fonts.md / config-i18n.md).
noto-fonts
noto-fonts-cjk
noto-fonts-emoji

# Log retention (apply.sh --logs). logrotate is the universal failsafe against

logrotate

# Mirror upkeep (apply.sh --mirrors). pacstrap bakes the installer's ranked
# mirrorlist into the machine and W had nothing to rebuild it with afterwards, so
# every install lived on a snapshot of its installation day (installer.md §5).
# reflector is the ranker the installer already uses on the ISO — the same tool
# with the same calibrated numbers, driven from /etc/w/mirrors.conf by w-mirrors.
# The cost of adding it is genuinely small: 158 KiB installed and its only
# dependency is `python`, which base.txt already installs explicitly. Writing our
# own ranker instead was rejected — --score/--age come from the Arch mirror status
# API, so a home-grown one would have to reimplement that client and re-measure
# numbers Ф.1 already measured. See w-mirrors.md.
reflector

# Network discovery — avahi+nss-mdns resolve *.local; gvfs (+backends) browses and

# gvfs-nfs. Phones: gvfs-afc (iOS, pulls usbmuxd+libimobiledevice) + gvfs-mtp.

# Foreign filesystems — Windows NTFS, cross-platform exFAT, Apple APFS. APFS is a

# needs dkms + headers for the active kernel. W default is linux-zen, so the
# zen headers are what apfs-rw builds against (w-kernel keeps them paired on
# switch). HFS+ needs no package (in-kernel hfsplus module).
ntfs-3g
exfatprogs
linux-apfs-rw-dkms
dkms          # linux-zen-headers for DKMS builds already come with base.txt

# ── Printing + scanning (apply.sh --printing) ─────────────────────────────────
# Driverless-first (IPP Everywhere / AirPrint), zero vendor PPD databases. Network
# printers are found via mDNS (avahi+nss-mdns, already installed above). cups is
# the server (lp/lpr/lpadmin CLI + web UI on localhost:631); cups-pk-helper lets
# system-config-printer do admin through polkit (→ hyprpolkitagent/fingerprint,
# no sudoers). cups-filters+ghostscript rasterize PDF for printers that only take
# PWG-Raster/URF. ipp-usb is the modern driverless USB bridge: it exposes an
# IPP-over-USB (AirPrint) printer/MFP as a local IPP service, so both printing and
# eSCL scanning work over USB with no vendor driver. cups-browsed is deliberately
# NOT relied on and gets masked by the module (source of the 2024 CUPS RCE CVEs).
# Scanning: sane + sane-airscan (driverless eSCL/WSD over network & ipp-usb) with
# simple-scan (GTK) as the GUI. GUI printer tool: system-config-printer (GTK3,
# auto-themed live by the w-style gtk axis).
cups
cups-pk-helper
cups-filters
ghostscript
ipp-usb
system-config-printer
sane
sane-airscan
simple-scan
