# w-i18n-src: 8412797dd0d9230d3f58f57a5c9e63aa9e4375a6af70a81d8f1e483e277808bd
Использование: w-firewall <команда>

Info: Переключение зоны файрвола между домашней и публичной (firewalld).

Команды:
  status        Зона по умолчанию, активные зоны и набор правил зоны по умолчанию
  home          Зона по умолчанию — 'home'  (база W: входящие ssh + mdns)
  public        Зона по умолчанию — 'public' (чужие сети; только входящий ssh)
  help          Показать эту справку

Коды выхода:
  0  Успех
  1  Ошибка выполнения
  2  Ошибка вызова

Примеры:
  w-firewall status
  sudo w-firewall public
