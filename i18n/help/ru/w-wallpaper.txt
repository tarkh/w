Использование: w-wallpaper <команда> [параметры]

Info: Выбор обоев под текущую ступень разрешения.

Команды:
  set [--monitor N]       Определить разрешение монитора и обновить симлинк обоев
                            --monitor N  Взять монитор с индексом N (по умолч. 0)
  get [--real]            Напечатать путь текущих обоев
                            --real       Напечатать сам файл, а не путь симлинка
  apply [--wait [СЕК]]    Поставить обои на все мониторы через IPC hyprpaper
                            --wait [СЕК] Ждать сокет hyprpaper (по умолч. 10с)
  tiers [--porcelain]     Список ступеней разрешения, которые может нести тема
                            --porcelain  По одному ШИРИНАxВЫСОТА в строке, крупные
  cover <ШИРИНАxВЫСОТА>   Напечатать, насколько показываемый мастер растянут,
                          чтобы заполнить панель такого размера в пикселях (cover)
  help, --help            Показать эту справку

Коды выхода:
  0  Успех
  1  Ошибка выполнения (нет файла, битый симлинк, hyprpaper не готов и т.п.)
  2  Ошибка вызова (неизвестная команда или параметр)

Примеры:
  w-wallpaper set
  w-wallpaper set --monitor 1
  w-wallpaper get
  w-wallpaper apply
  w-wallpaper apply --wait
  w-wallpaper apply --wait 5
  w-wallpaper tiers --porcelain
  w-wallpaper cover 2880x1800
