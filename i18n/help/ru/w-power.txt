# w-i18n-src: c7cce9534568a10389ca12769355735cd4ee1909eb36fca2e6067f29ad175b5a
Использование: w-power <команда> [аргументы]

Info: Схемы питания, политика простоя (блокировка/экран/сон), крышка, лимит заряда.

Команды:
  status                     Режим, схема, батарея, таймеры простоя, состояние hypridle
  profile <имя>              Сменить схему сразу (performance|balanced|power-saver)
  profile auto on|off        Автопереключение схемы на сеть<->батарею (root)
  idle <ac|bat> <lock|display|suspend> <секунды>
                             Задать звено каскада (0 = выкл), ОТНОСИТЕЛЬНО предыдущего
  idle <ac|bat> kbdlight <секунды>
                             Гасить подсветку клавиатуры через N с простоя (0 = никогда);
                             не входит в каскад, считается от последней активности
                             связь: lock считается от последней активности, display — от
                             срабатывания lock, suspend — от срабатывания display;
                             перегенерирует hypridle (пользователь). display < 5
                             принимается, но с предупреждением (hyprlock нужен
                             включённый экран, чтобы снять свой фон)
  charge-limit <0..100>      Потолок заряда батареи, напр. 80 (root; прошивка ноутбука)
  lid <ac|bat|docked> <lock|suspend|ignore>
                             Действие при закрытии крышки по состоянию питания (root)
  lid-wake <auto|keep>       Может ли крышка будить машину (root). auto (по умолчанию)
                             убирает её из источников пробуждения ACPI при уходе в сон с
                             УЖЕ ОТКРЫТОЙ крышкой — где она бесполезна, а на части
                             будит машину через считанные секунды — и возвращает при
                             пробуждении, так что закрыть-открыть крышку всё ещё будит.
                             keep вообще не трогает источники пробуждения.
  power-key <poweroff|suspend|menu|ignore>
                             Действие кнопки питания (root; menu = меню питания W)
  mode <laptop|desktop|auto> Применить пресет режима машины ко всем ручкам (root)
  apply                      Перегенерировать все узлы из $CONF (root)
  help                       Показать эту справку

Параметры:
  --user <имя>               Работать для этой учётной записи, а не вызвавшего (root).
                             apply.sh --power использует это, чтобы отрисовать политику
                             простоя всех учётных записей, а не только первой.

Системная политика: $CONF   Пользовательские правки простоя: ~/.config/w/power.conf

Коды выхода: 0 успех · 1 ошибка выполнения/проверки · 2 ошибка вызова

Примеры:
  w-power status
  w-power profile performance
  w-power idle bat suspend 600
  sudo w-power charge-limit 80
  sudo w-power lid ac ignore
  sudo w-power lid-wake keep
  sudo w-power mode laptop
