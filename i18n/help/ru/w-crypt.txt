# w-i18n-src: c7e4e266a048f08958192d4dede12b2ae813767f13c703d0fc826993c2338d7c
Использование: w-crypt <команда>

Info: Управление факторами шифрования диска — авторазблокировка TPM2 и ключи восстановления.

Команды:
  status [--porcelain]
                 Показать LUKS-устройство, слоты ключей и токены (TPM2/восстановление);
                  --porcelain: одна TSV-строка luks/tpm_device/tpm2/pcrs/recovery/reseal
  enroll-tpm [--pin] [--no-secureboot]
                 Занести авторазблокировку TPM2 (PCR: ${W_CRYPT_TPM2_PCRS}) взамен прежней;
                  раз спросит пароль. --pin — ещё и PIN при каждой загрузке.
                  Отказ, пока Secure Boot выключен: без него TPM отдаёт ключ
                  любому загрузочному носителю (--no-secureboot — обойти)
  reenroll-tpm   Переустановить TPM2 под текущую загрузку (после смены прошивки/Secure Boot)
  recovery-add [--replace]
                 Создать и напечатать одноразовый ключ восстановления (хранить офлайн);
                  --replace удаляет прежний ключ восстановления
  wipe-tpm       Убрать токен TPM2 (вернуться к разблокировке только паролем)
  help           Показать эту справку

Коды выхода:
  0 Успех   1 Ошибка выполнения   2 Ошибка вызова

Примеры:
  sudo w-crypt status
  sudo w-crypt enroll-tpm --pin
  sudo w-crypt recovery-add --replace
