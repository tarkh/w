# w-i18n-src: 5594eb64261c13380efcd0590f67e066e0c4a65b3a3c95bf1d518b4db2ba43fe
Использование: w-rollback <команда> [параметры]

Info: Откат системы к btrfs-снапшоту, на любом из путей загрузки.

Команды:
  status [--porcelain]  Откуда загружена система и что сделает откат
  list [--porcelain]    Снапшоты, доступные для отката (--porcelain: номер, тип,
                        парный pre-ID, дата ISO и описание, по одной TSV-строке)
  run [<номер>]         Выполнить откат (интерактивно; спросит перед изменениями)
  launch [<номер>]      Открыть 'run' в окне терминала, пароль спросит там
  help                  Показать эту справку

Откат никогда не удаляет систему, которую заменяет: уходящий корень сохраняется и
может быть загружен снова. Полная процедура — в /usr/share/doc/w/RECOVERY.md,
включая случай, когда машина уже вовсе не загружается.

Коды выхода:
  0  Успех
  1  Ошибка выполнения
  2  Ошибка вызова

Примеры:
  w-rollback status
  sudo w-rollback run
